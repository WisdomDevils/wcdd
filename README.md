# wcdd.de

Single-page poster site for [wcdd.de](https://wcdd.de).

## Git practice

This repo is a working example of the loop:

1. Edit on a branch (`feat/landing`)
2. Open a pull request and read the diff
3. Merge when it looks right
4. Vercel deploys the result

If a change looks wrong, revert the commit instead of guessing. The previous snapshot is still there.
